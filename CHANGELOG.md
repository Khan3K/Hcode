# Changelog

All notable changes to this project are documented in this file.

## [2.0.0] - 2026

### Added
- Initial public release of the H-Code transformation engine.
- Web UI, REST API, and PHP library interface.
- Support for OpenAI, Anthropic, Gemini, DeepSeek, Groq, Together,
  DeepInfra, OpenRouter, Pollinations, and Puter providers.
- Provider-agnostic humanization with intensity levels.
