# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Email the maintainer directly, or report privately via
[GitHub Security Advisories](https://github.com/Khan3K/Hcode/security/advisories/new)
if available. You should receive an acknowledgment within 72 hours.

Include:
- the version affected,
- a minimal reproduction,
- the impact, if you have assessed it.

## Notes

`data/` is meant to hold local configuration only and should never be
committed to version control with real credentials.
